# Phase 10 — Assessment Engine Specification

## Overview
Evaluates technical competence across multiple problem formats and time-restricted challenges.

---

## 1. Supported Assessment Formats
- **Coding Challenges**: Standard input/output algorithm challenges with hidden test cases.
- **MCQ Tests**: Multiple choice technical assessments.
- **Project Reviews**: Code repository quality & architecture audits.
- **Debugging Challenges**: Finding and patching memory leaks & race conditions.
- **System Design**: Architectural diagramming & state flow evaluation.
